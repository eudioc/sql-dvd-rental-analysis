Анализ базы данных DVD Rental

Описание проекта
Анализ бизнес-метрик онлайн-сервиса аренды фильмов с использованием SQL. 
Цель проекта — продемонстрировать навыки аналитического мышления и владение SQL.

Ключевые метрики анализа
1. Финансовые показатели: общая выручка, динамика по месяцам, ARPC
2. Анализ клиентов: сегментация по активности, VIP-клиенты
3. Анализ контента: популярные жанры, самые доходные фильмы
4. Операционные показатели: доступность фильмов, нагрузка на инвентарь

Результаты анализа
Топ-3 вывода:
1. Самый доходный жанр — Sports (17% от общей выручки)
2. VIP-клиенты (6% от общей базы) приносят 35% выручки
3. Пик аренд приходится на летние месяцы (июль-август)

2. Рекомендации для бизнеса:
- Создать программу лояльности для VIP-клиентов
- Увеличить количество копий фильмов в жанре Sports
- Планировать маркетинговые акции на февраль-март (низкий сезон)

Как запустить проект
1. Установите PostgreSQL
- Для Ubuntu/Debian

sudo apt-get install postgresql postgresql-contrib

Для Windows скачайте с official сайта

2. Восстановите базу данных из файла dvdrental.tar
- Скачайте dvdrental.tar
- Восстановление:

createdb dvdrental

pg_restore -U postgres -d dvdrental dvdrental.tar

3. Выполните запросы из файла `dvd_rental_analysis.sql`
- Откройте pgAdmin или psql
- Подключитесь к базе dvdrental
- Выполните запросы из файла queries/analysis.sql
